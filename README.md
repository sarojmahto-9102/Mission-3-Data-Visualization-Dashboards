# Mission-3-Data-Visualization-Dashboards
# Project Overview
An interactive Superstore Sales Dashboard built using Google Looker Studio. Includes key performance indicators, sales and profit charts, interactive filters, drill-down analysis, and data storytelling to explore business performance and trends.
# Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Average Discount
- Profit Margin
# Dashboard Charts
1. Monthly Sales Trend
2. Sales by Category
3. Profit by Sub-Category
4. Discount vs Profit by Sub-Category
# Interactive Features
- Date Range, Region, Category, and Segment Filters
- Category-to-Sub-Category Drill-Down
# Key Insights
Technology has the highest sales among the product categories. Monthly sales fluctuate, and profitability varies across sub-categories, with some generating losses.
